# CRM Система для управления магазином

Полнофункциональная CRM система для управления небольшим магазином на Django. Система позволяет эффективно управлять товарами, заказами, клиентами и поставщиками, отслеживать остатки на складе, списывать товары при создании заказов и отправлять email-уведомления клиентам.

Система включает в себя дашборд с аналитикой продаж, управление складскими остатками с уведомлениями о низких остатках, автоматический расчет прибыли и маржинальности товаров, а также полную историю взаимодействий с клиентами.

## Features

- **Управление товарами**: добавление, редактирование, отслеживание остатков, управление ценами (закупочная и продажная), артикулы и штрих-коды, поиск по названию, описанию, артикулу, штрих-коду и категории
- **Управление заказами**: создание заказов с несколькими позициями, отслеживание статусов (ожидает, в обработке, завершен, отменен), управление оплатой (не оплачено, частично, оплачено), поиск клиентов и товаров при создании заказа
- **Управление клиентами**: база клиентов с историей покупок, статистика покупок (всего заказов, потрачено, средний чек), поиск по имени, email и телефону
- **Управление поставщиками**: информация о поставщиках товаров с контактными данными, поиск по названию, контактному лицу и телефону
- **Категории товаров**: организация товаров по категориям, поиск по названию и описанию
- **Дашборд**: статистика продаж, остатки товаров, последние заказы, топ товары по продажам
- **Аналитика**: детальная отчетность по заказам, выручке, разбивка по статусам и способам оплаты
- **Уведомления о низких остатках**: автоматическое отслеживание остатков и предупреждения
- **Email-уведомления**: автоматическая отправка email клиентам при создании заказа и изменении статуса
- **Автоматическое списание товаров**: товары автоматически списываются со склада при завершении заказа
- **Поиск и фильтрация**: регистронезависимый поиск по всем сущностям, фильтрация заказов по статусу и дате
- **Удобный интерфейс**: поиск клиентов и товаров через текстовые поля с автодополнением при создании заказа

## Tech Stack

### Backend
- **Python 3.8** — основной язык программирования
- **Django 4.2** — веб-фреймворк
- **SQLite** — база данных

### Frontend
- **Bootstrap 5** — CSS-фреймворк для UI
- **HTML5/CSS3** — разметка и стилизация
- **JavaScript** — для AJAX-запросов и динамического взаимодействия

### Библиотеки
- **python-dotenv** — для управления переменными окружения
- **Django Email Backend** — для отправки email-уведомлений (SMTP)

### Инструменты разработки
- **Django Admin** — административная панель
- **Django Management Commands** — команды для управления системой

## Installation

### Требования
- Python 3.8 или выше
- pip (менеджер пакетов Python)

### Пошаговая инструкция

1. **Клонирование репозитория**
   ```bash
   git clone <repository-url>
   cd crm1
   ```

2. **Создание виртуального окружения**
   ```bash
   python -m venv venv
   ```
   
   Активация виртуального окружения:
   - **Windows:**
     ```bash
     venv\Scripts\activate
     ```
   - **macOS/Linux:**
     ```bash
     source venv/bin/activate
     ```

3. **Установка зависимостей**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройка переменных окружения (опционально)**
   
   Создайте файл `.env` в корне проекта для настройки email:
   ```env
   EMAIL_HOST=smtp.gmail.com
   EMAIL_PORT=587
   EMAIL_USE_TLS=True
   EMAIL_HOST_USER=your-email@gmail.com
   EMAIL_HOST_PASSWORD=your-app-password
   DEFAULT_FROM_EMAIL=your-email@gmail.com
   ```
   
   Если переменные окружения не указаны, email будет выводиться в консоль (для development).

5. **Применение миграций**
   ```bash
   python manage.py makemigrations
   python manage.py migrate
   ```

6. **Создание суперпользователя**
   ```bash
   python manage.py createsuperuser
   ```
   
   Введите имя пользователя, email и пароль для доступа к админ-панели Django.

7. **Запуск сервера разработки**
   ```bash
   python manage.py runserver
   ```

8. **Доступ к приложению**
   
   Откройте браузер и перейдите по адресу:
   - **Главная страница:** http://127.0.0.1:8000
   - **Админ-панель:** http://127.0.0.1:8000/admin

9. **Регистрация нового пользователя**
   
   На главной странице нажмите "Регистрация" для создания нового аккаунта. Все новые пользователи автоматически получают права администратора.

### Основные сущности:

- **Category** — категории товаров
- **Supplier** — поставщики товаров
- **Product** — товары (связь с категорией и поставщиком)
- **Customer** — клиенты магазина
- **Order** — заказы/продажи (связь с клиентом)
- **OrderItem** — позиции заказа (связь с заказом и товаром)

### Связи:

- `Category` → `Product` (один-ко-многим)
- `Supplier` → `Product` (один-ко-многим)
- `Customer` → `Order` (один-ко-многим)
- `Order` → `OrderItem` (один-ко-многим)
- `Product` → `OrderItem` (один-ко-многим)

### Основные URL-маршруты

#### Аутентификация
- `/register/` — регистрация нового пользователя (автоматически получает права администратора)
- `/login/` — вход в систему
- `/logout/` — выход из системы

#### Дашборд и аналитика
- `/` — главная страница (дашборд)
- `/analytics/` — страница аналитики

#### Товары
- `/products/` — список товаров (с поиском и фильтрацией)
- `/products/<id>/` — детали товара
- `/products/create/` — создание товара
- `/products/<id>/edit/` — редактирование товара
- `/products/<id>/delete/` — удаление товара

#### Заказы
- `/orders/` — список заказов (с фильтрацией по статусу и дате)
- `/orders/<id>/` — детали заказа
- `/orders/create/` — создание заказа (с поиском клиентов и товаров)
- `/orders/<id>/edit/` — редактирование заказа
- `/orders/<id>/delete/` — удаление заказа

#### Клиенты
- `/customers/` — список клиентов (с поиском)
- `/customers/<id>/` — детали клиента
- `/customers/create/` — создание клиента
- `/customers/<id>/edit/` — редактирование клиента
- `/customers/<id>/delete/` — удаление клиента

#### Поставщики
- `/suppliers/` — список поставщиков (с поиском)
- `/suppliers/<id>/` — детали поставщика
- `/suppliers/create/` — создание поставщика
- `/suppliers/<id>/edit/` — редактирование поставщика
- `/suppliers/<id>/delete/` — удаление поставщика

#### Категории
- `/categories/` — список категорий (с поиском)
- `/categories/create/` — создание категории
- `/categories/<id>/edit/` — редактирование категории
- `/categories/<id>/delete/` — удаление категории

### Компоненты системы:

1. **Browser (Клиент)** — веб-браузер пользователя
2. **Django Application** — основное приложение:
   - **URL Routing** — маршрутизация запросов
   - **Views** — обработка запросов и бизнес-логика
   - **Forms** — валидация и обработка форм
   - **Models** — модели данных (ORM)
3. **SQLite Database** — база данных для хранения информации
4. **Email Backend** — отправка email-уведомлений клиентам
