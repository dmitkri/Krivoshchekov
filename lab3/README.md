# Лабораторная работа 3

## Описание

В этой работе нужно было реализовать три коллекции: список, словарь и двусвязный список. Все они работают без использования готовых коллекций из .NET.

## Что реализовано

### 1. SimpleList

Это простой список, который хранит элементы в массиве. Когда массив заполняется, создается новый массив в два раза больше.

**Что умеет:**
- Добавлять элементы в конец
- Удалять элементы
- Искать элементы
- Получать элементы по индексу
- Вставлять элементы в любое место

**Пример:**
```csharp
var list = new SimpleList<int>();
list.Add(1);
list.Add(2);
list.Add(3);
Console.WriteLine(list[0]); // выведет 1
list.Remove(2);
Console.WriteLine(list.Count); // выведет 2
```

### 2. SimpleDictionary

Это словарь, который хранит пары ключ-значение. Использует хеш-таблицу для быстрого поиска.

**Что умеет:**
- Добавлять пары ключ-значение
- Получать значение по ключу
- Удалять элементы по ключу
- Проверять, есть ли ключ в словаре

**Пример:**
```csharp
var dict = new SimpleDictionary<string, int>();
dict.Add("один", 1);
dict.Add("два", 2);
Console.WriteLine(dict["один"]); // выведет 1
dict.Remove("один");
```

### 3. DoublyLinkedList

Это двусвязный список. Каждый элемент знает о предыдущем и следующем элементе. Это позволяет быстро вставлять и удалять элементы.

**Что умеет:**
- Добавлять элементы в конец
- Удалять элементы
- Вставлять элементы в любое место
- Искать элементы

**Пример:**
```csharp
var list = new DoublyLinkedList<int>();
list.Add(1);
list.Add(2);
list.Insert(1, 10);
Console.WriteLine(list[1]); // выведет 10
```

## Как это работает

### SimpleList
Использует обычный массив. Когда массив заполняется, создается новый массив в два раза больше, и все элементы копируются туда.

### SimpleDictionary
Использует хеш-таблицу. Ключ преобразуется в число (хеш-код), и по этому числу определяется, в какую корзину положить элемент. Если в одной корзине несколько элементов, они хранятся в цепочке.

### DoublyLinkedList
Каждый элемент (узел) хранит ссылку на предыдущий и следующий элемент. Это позволяет быстро вставлять и удалять элементы, но поиск по индексу медленнее, чем в массиве.
